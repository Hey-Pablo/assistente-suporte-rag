## Como classificar um chamado de suporte principalmente

A classificação correta do chamado acelera a resolução e ajuda a equipe a entender a prioridade. Este artigo explica como classificar um chamado de suporte com base em critérios objetivos.

### Critérios de classificação

#### Por categoria

| Categoria | Descrição | Exemplo |
|-----------|-----------|---------|
| Hardware | Problema físico na máquina | Monitor não liga |
| Software | Aplicação travada | Sistema não inicia |
| Rede | Conexão instável | Internet cai |
| impressora | Falha na impressão | Papel preso |
| Boleto | Problemas de pagamento | DARF vencido |
| Contábil | Questões fiscais | NF-e rejeitada |
| User | Questão do usuário | Esqueci senha |
| Config | Configuração | Impressão errada |

#### Por prioridade

| Prioridade | Tempo de resposta | SLAs | Exemplo |
|------------|-------------------|------|---------|
| Crítica | 30 minutos | 1h | Sistema offline |
| Alta | 2 horas | 4h | PF não funciona |
| Normal | 4 horas | 1 dia | Impressora lenta |
| Baixa | 1 dia | 2 dias | Sua solicitação |

### Passos para classificação

1. **Identifique o problema** - Pergunta clara do usuário
2. **Verifique categoria** - Use tabela acima
3. **Defina prioridade** - Baseado em impacto
4. **Atribua equipe** - Conforme especialização
5. **Adicione SLA** - Prazo de resolução

### Template de classificação

```
Problema: [Descrição curta]
Categoria: [Hardware/Software/Rede/etc.]
Prioridade: [Crítica/Alta/Normal/Baixa]
Impacto: [Número de usuários afetados]
SLA: [Tempo máximo de resolução]
Observação: [Detalhes adicionais]
```

### Regra do 3C

1. **Consistência** - Classifique todos igual
2. **Comunicação** - Informe o cliente o classificado
3. **Correção** - Ajuste se necessário

### Fluxo de atendimento

```
[Usuário abre chamado]
       ↓
[Classificações automáticas (se houver)]
       ↓
[Classificação manual] → [Categoriza] → [Prioriza]
       ↓
[Atribui para equipe] → [SLA configurado]
       ↓
[Atendimento] → [Resolução] → [Fechamento]
```

### Erros comuns

#### Classificação incorreta

- **Problema**: Chamado vai para equipe errada
- **Solução**: Revisar classificação no primeiro contato

#### Prioridade errada

- **Problema**: Crítico tratado como normal
- **Solução**: Reavaliar impacto imediatamente

#### SLA não configurado

- **Problema**: Não há prazo definido
- **Solução**: Sempre vincular SLA ao chamado

### KPIs de classificação

- Taxa de classificação correta: >95%
- Tempo de triagem: <5 minutos
- Chamados reclassificados: <5%
- SLA cumprido: >90%
