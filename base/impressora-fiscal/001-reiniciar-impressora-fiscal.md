## Como reiniciar uma impressora fiscal

Se sua impressora fiscal está travada, apresentando erros ou não respondendo a comandos, o procedimento de reinício pode resolver a maioria dos problemas temporários.

### Passos para reinicialização

1. **Aguarde o fim de quaisquer operações em andamento** - Não pressione botões enquanto a impressora está processando um documento.

2. **Desligue a impressora fisicamente** - Puxe o plugue da tomada ou use o interruptor de energia local, se disponível.

3. **Aguarde 30 segundos** - Este tempo permite que os componentes internos se estabilizem.

4. **Ligue novamente** - Conecte a impressora à tomada ou use o interruptor de energia.

5. **Verifique o status** - A tela da impressora deve mostrar "Pronta" ou um ícone semelhante.

6. **Teste com um documento simples** - Abra um cupom em teste ou use o modo de auto-teste para verificar o funcionamento.

### Quando o reinício não funciona

- Se o problema persistir, verifique os logs de erro na tela
- Consulte o manual do fabricante para códigos de erro específicos
- Entre em contato com o suporte técnico

### Precauções

- Não use o reinício como solução padrão, apenas para problemas temporários
- Sempre finalize corretamente os processos antes de desligar
- Evite reiniciar durante impressão de documentos fiscais reais
