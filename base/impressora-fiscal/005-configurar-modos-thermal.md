## Como configurar os modos de impressão térmica

A impressora fiscal pode operar em diferentes modos de impressão térmica, ajustando a qualidade e velocidade conforme a necessidade. Essa configuração é útil para diferentes tipos de papel e ambientes de uso.

### Modos disponíveis

1. **Velocidade máxima** - Para emissão rápida em ambientes com alto volume
2. **Qualidade padrão** - Configuração recomendada para uso diário
3. **Alta qualidade** - Para documentos que exigem melhor legibilidade
4. **Econômico** - Reduz consumo de energia e vida útil do cabeçote

### Como acessar as configurações

1. **Acesse o menu principal** - Use os botões de navegação do visor.

2. **Navegue até "Configurações"** - Geralmente localizado no menu "Utilitários" ou "Opções".

3. **Selecione "Modo de impressão"** - Opção que controla velocidade e qualidade.

4. **Escolha o modo desejado** - Siga as instruções no visor.

5. **Salve as alterações** - Confirme com o botão apropriado.

### Recomendações por cenário

| Cenário | Modo recomendado | Motivo |
|---------|------------------|--------|
| Balcão de atendimento | Velocidade máxima | Reduz fila de espera |
| Controle de qualidade | Alta qualidade | Melhor legibilidade |
| Uso noturno | Econômico | Reduz consumo |
| Uso padrão | Qualidade padrão | Equilíbrio |

### Verificação

Após alterar o modo, imprima um documento de teste para garantir que a configuração está correta.
