## Como fazer o reset de erros padrão da impressora fiscal

Muitos erros na impressora fiscal podem ser resolvidos com o procedimento de reset padrão. Este método limpa memória temporária e reinicializa o sistema.

### Passos para reset padrão

1. **Desligue a impressora** - Puxe o plugue da tomada.

2. **Pressione e segure os botões de FUNÇÃO e IMPRIME** simultaneamente.

3. **Ligue a impressora novamente** - Enquanto mantém os botões pressionados, conecte à tomada.

4. **Aguarde o procedimento** - Mantenha os botões pressionados por aproximadamente 10 segundos, até que o visor mostre "RESET" ou um indicador de limpeza.

5. **Solte os botões** - Após o reset, a impressora deve iniciar normalmente.

6. **Verifique o status** - O visor deve mostrar "Pronta" ou indicador verde de funcionamento.

### Quando usar este procedimento

- Erro "Bateria fraca" aparecendo sem motivo
- Memória temporária cheia ou travamento interno
- Avisos de "Comunicação com o PA" repetidos
- Display apresentando símbolos estranhos

### Atenção

- Este reset não apaga dados de programação ou parâmetros
- Pera executar reset durante impressão de documentos reais
- Após o reset, pode ser necessário verificar conexões USB ou rede
